## Objetivo

El ruleset debe poder aplicarse tambien en Cline y Roo Code (extensiones de
VS Code), reutilizando `AGENTS.md` como fuente de reglas compartida y
documentando el mecanismo de inyeccion propio de cada herramienta.

## Criterios de aceptacion

- Las guias de integracion para Cline y Roo Code estan documentadas en
  `docs/INTEGRACION-ASISTENTES.md`, con fuentes oficiales citadas.
- El documento explica como inyectar `AGENTS.md` en cada herramienta:
  `.clinerules` (archivo o directorio) para Cline y `.roo/rules/` (o
  `.roorules` legacy) para Roo Code.
- El documento declara honestamente la garantia: son instrucciones de texto,
  sin bloqueo determinista equivalente a los `deny` de `opencode.json` /
  `kilo.json`, salvo los mecanismos nativos de permisos de cada herramienta.
